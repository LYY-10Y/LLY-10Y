## 🔭 Focus

- **操作系统研发**：10Y OS 的内核、驱动与运行时，面向多设备与互联场景，把 AI 能力和分布式架构做进系统层
- **硬件平台**：HY 智能硬件平台的计算与感知模块设计，配套底层固件与调试工具
- **Android 工具链**：USB CDC 串口与蓝牙 BLE 连接、MicroPython 固件刷写、Material 3 界面、平板与折叠屏适配
- **开源与协作**：以 MIT 协议公开源码与开发者接口，按 stable / preview / dev 三通道持续维护并响应反馈
